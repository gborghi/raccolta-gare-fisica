*Instructions for the electronic stopwatches with lap memory used in the IZhO 2026 experimental competition ([[prove/izho-2026-physexp_eng#q01|IZhO 2026 · Problema 1]]). This is not a problem: the sheet only describes the equipment.*

### Stopwatch model FS-810

**ENGLISH LANGUAGE**

![[Instruction_Stopwatch_eng_p1_f1.png]]

Button A — start/stop.
Button B — Split/Lap memory (stage memory).
Button C — Record splits / Reset.
Button D — Mode (do not use).

**Recording split (stage) times**
1. At the start, press Button A (time = 0).
2. At the end of Stage 1, press Button C (the stopwatch memory stores the time for Stage 1). At the end of Stage 2, press Button C again (the memory stores the cumulative time for Stages 1–2), and so on.
3. After completing 10 stages, press Button A (stop the stopwatch).

**Reading split (stage) times**
1. Press Button B (switch to split-time reading mode).
2. Press Button C (the display will show the cumulative time for the stages).
3. By pressing Button C repeatedly, you can read the cumulative times from Stage 1 to Stage 10. (In the figure: Stage 8 and the cumulative time for 8 stages is 7.13 s.)
4. To return to split-time recording mode, press Button B.
5. To clear the split memory, press Button C.

**If necessary, you can repeat the split recording and reading process.**

*Istruzioni dei cronometri elettronici con memoria dei giri (lap) usati nella prova sperimentale IZhO 2026 ([[prove/izho-2026-physexp_eng#q01|IZhO 2026 · Problema 1]]). Non è un problema: il foglio descrive solo l’attrezzatura.*

### Cronometro modello FS-810

![[Instruction_Stopwatch_eng_p1_f1.png]]

Pulsante A — avvio/arresto.
Pulsante B — memoria Split/Lap (memoria delle tappe).
Pulsante C — registrazione degli split / azzeramento.
Pulsante D — Mode (non usare).

**Registrazione dei tempi di tappa (split)**
1. Alla partenza premere il pulsante A (tempo = 0).
2. Alla fine della tappa 1 premere il pulsante C (la memoria del cronometro registra il tempo della tappa 1). Alla fine della tappa 2 premere di nuovo il pulsante C (la memoria registra il tempo cumulativo delle tappe 1–2), e così via.
3. Completate 10 tappe, premere il pulsante A (arresto del cronometro).

**Lettura dei tempi di tappa (split)**
1. Premere il pulsante B (passaggio alla modalità di lettura degli split).
2. Premere il pulsante C (il display mostra il tempo cumulativo delle tappe).
3. Premendo ripetutamente il pulsante C si leggono i tempi cumulativi dalla tappa 1 alla tappa 10. (Nella figura: tappa 8, tempo cumulativo delle 8 tappe 7,13 s.)
4. Per tornare alla modalità di registrazione degli split, premere il pulsante B.
5. Per cancellare la memoria degli split, premere il pulsante C.

**Se necessario, si può ripetere la registrazione e la lettura degli split.**
